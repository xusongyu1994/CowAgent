⚠️ 本原型的简化（方案里都是完整设计，见 §0.23）
· 企微通知：只弹 toast —— 方案里 一期只推 4 类（被拉入 / 被派活 / @提及 / 升级待处置），其余 20 类二期；推送幂等键、每分钟上限、提醒去重位都不在原型模拟
· 未读：单一演示值（只有"打开节点即已读"与"归档清零"两种变化）
· 权限：前端提前拦一次（归档只读 / 只读成员 / 发起人处置），真实现由后端接口再校验
· 单实例锁 / 配额 / 分卷 zip / 导出：只在方案与文案里，原型不实现
· 文件上传：讨论附件与阶段结果用"演示文件"模拟落盘
· 通知撤回：企微平台不支持，原型也不做"撤回已发通知"
① 数据模型（一棵树）
nodes.parent_id 自引用建树，层级不限
flow_members = 可见性边界（看全树）
node_members = 编辑权 + 通知对象
messages.parent_id = 批注回复
files.kind = discussion / result
events = 操作日志 → 唯一出口是「📜 操作记录」
唯一性由 DB 保证：uq_files_display / uq_files_current 两个部分唯一索引
② 文件管理（v0.5）
磁盘名 = `{file_id}.{ext}` 永久唯一
展示名 = display_name 同名自动加 (2)
存储 = 独立根目录 + 流程/节点/类型分层
删除 = 上传者/发起人；软删除进回收站
四层视图 = 节点内 / 流程总览 / 回收站 / 我的文件
③ 可复用（无需重写）
企微 OAuth 免密登录 + HMAC 会话
独立页渲染（同 /analysis）
通讯录同步（部门 + 姓名）
上传 / 预览 / 下载 + 路径安全
企微应用消息主动推送
无依赖 SVG 力导向图
④ 本期不做
审批 / 会签 / 或签语义
图片、PDF 上圈选打点批注
甘特图 / 工时 / 成本
外部联系人协作
文件正文检索（PDF/Word 抽取，二期）
AI 摘要与流程日报（二期）
